# Контекст текущей сессии — синхронный обмен 1С УНФ 3.0 → Единая база

> Файл создан для быстрого входа в задачу после очистки контекста разговора.

## Что настраиваем

Синхронный обмен данными из 1С УНФ 3.0 в Laravel-бэкенд на `gbsale.ru` (Beget shared hosting).

## Состояние на стороне сайта (Laravel)

- Добавлены массовые эндпоинты:
  - `POST /api/1c/prices/sync` — принимает пачку цен, создаёт товар/offer при отсутствии.
  - `POST /api/1c/stocks/sync` — принимает пачку остатков, создаёт товар/offer при отсутствии, не трогает `reserved`.
- В `OneCSyncService` при импорте цен/остатков товар/offer создаётся автоматически, если не найден.
- Endpoint `POST /api/1c/prices` (одиночная цена) оставлен для обратной совместимости.
- Задеплоено на Beget: миграции, кэши и индекс бота перестроены.

## Состояние расширения 1С `GadgetBarIntegration`

- Общий модуль `ЕдинаяБазаGB` (префикс `GadgetBar_`).
- Регистр сведений `GadgetBar_ОчередьОбмена`.
- Регламентное задание `GadgetBar_ВыгрузкаВЕдинуюБазу` (создано, но в файловой базе не запускается автоматически).
- Подписки на события:
  - `ПриЗаписи` справочника `Номенклатура` → `ЕдинаяБазаGB.ПриЗаписиНоменклатуры`.
  - `ОбработкаПроведения` документа `УстановкаЦенНоменклатуры` → `ЕдинаяБазаGB.ПриПроведенииУстановкиЦен`.
  - `ОбработкаПроведения` документов остатков → `ЕдинаяБазаGB.ПриПроведенииДокументаОстатков`.
- Исправлено имя табличной части в документе «Установка цен»: теперь определяется автоматически (`Запасы` или `Товары`).
- Добавлены отладочные `Сообщить` и записи в журнал регистрации.

## Логика отправки (актуальная версия модуля)

- Цены: пачкой строк документа «Установка цен» в endpoint `/api/1c/prices/sync`. В файловой базе фоновые задания не работают, поэтому после записи в очередь запись отправляется синхронно в том же сеансе (1С блокируется на время одного HTTP-вызова, таймаут 5 секунд).
- Остатки: пачкой строк документа синхронно в endpoint `/api/1c/stocks/sync`.
- Номенклатура: при записи в очередь `/api/1c/products`, затем синхронная отправка (как цены).

- Добавлено авто-создание товара/offer при отсутствии.

- Убрана попытка запуска фоновых заданий для файловой базы — теперь отправка синхронная.

## Что нужно проверить

1. Убедиться, что в конфигураторе 1С в модуле `ЕдинаяБазаGB` процедура `ПриПроведенииУстановкиЦен` вызывает:
   ```1c
   ДобавитьВОчередь("/api/1c/prices/sync", Новый Структура("items", МассивЦен));
   ```
2. Провести документ «Установка цен номенклатуры».
3. В окне сообщений 1С должно появиться:
   - `GadgetBar: вызвана подписка ПриПроведенииУстановкиЦен`
   - `GadgetBar: ДобавитьВОчередь /api/1c/prices/sync`
   - `GadgetBar: отправлено /api/1c/prices/sync -> 200`
4. Проверить `integration_logs` на сайте — должна появиться запись `api/1c/prices/sync` с массивом цен.
5. Проверить таблицу `prices` — должны обновиться цены.
